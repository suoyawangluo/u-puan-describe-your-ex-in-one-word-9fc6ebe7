## Entry

**Placeholder**

One word describing an ex: you were just keeping the seat warm until the
real thing came along. A twist, not a plain insult — the whole relationship
reframed as a temp hire, understated enough to sting.

## How it works

`main.ts` assembles the word from its parts (`Place` + `hold` + `er`),
validates it against the gate (1–111 characters, exactly one word, one
line), writes it to `/output/entry.txt`, then reads it back and verifies
the sha256 matches.

```sh
node main.ts
```
